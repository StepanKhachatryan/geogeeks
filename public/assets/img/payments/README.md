Put the Idram QR image here as `idram-qr.png`.

The payment gate renders `/assets/img/payments/idram-qr.png` once a visitor has
entered a valid phone number. Crop the export from the Idram app down to the QR
square itself, without the ID caption underneath: the page prints the ID as text
next to it. Any square PNG works; 600×600 or larger stays sharp on a
high-density screen.

If the file is missing the gate still works. It drops the picture and shows the
Idram ID on its own, so a customer can pay by ID from inside the app.
